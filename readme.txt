# federated_cifar10

**위원회(Committee) 평가 기반 기여도 가중 연합학습(FedContrib)** 의 실험 환경입니다.
[Flower](https://flower.ai) 시뮬레이터로 CIFAR-10 연합학습을 돌리면서, 악의적인 참여자(랜덤 노이즈 / 데이터 포이즈닝)가 섞였을 때 **표준 FedAvg**와 **기여도 기반 집계**의 성능을 비교합니다.

> Ph.D. 연구 프로젝트의 연합학습 파트입니다. 같은 기여도 평가·위원회 구조를 블록체인으로 구현한 저장소는 [flmainchain](https://github.com/skg4463/flmainchain), [flstorage](https://github.com/skg4463/flstorage), [fls-client](https://github.com/skg4463/fls-client)입니다.

## 핵심 아이디어

일반적인 평균 집계(FedAvg)는 모든 클라이언트 모델을 그대로 평균하므로, 악의적인 모델도 그대로 섞입니다.
FedContrib은 매 라운드 **위원회가 각 클라이언트 모델을 직접 평가**하고, 평가 점수가 높은 모델에 더 큰 가중치를 줍니다.

```
라운드 r
 ├─ 1. 클라이언트 10명이 로컬 학습 (정상 / 노이즈 공격 / 포이즈닝 공격)
 ├─ 2. 위원회 3명이 각 클라이언트 모델을 자신의 테스트셋으로 평가 → 평균 정확도 a
 ├─ 3. EWMA로 누적:   s ← β·a + (1−β)·s
 ├─ 4. 가중치 계산:   w = s^csf / Σ s^csf
 └─ 5. 가중 평균으로 글로벌 모델 생성 → 전체 테스트셋으로 평가
```

- **EWMA(β)**: 한 라운드의 우연한 점수 변동을 줄이고 과거 성적을 반영합니다.
- **csf (Contribution Scaling Factor)**: 점수에 거듭제곱을 취해 점수 차이를 증폭합니다. 1이면 점수에 정비례, 클수록 성능 좋은 모델에 가중치가 몰립니다.
- `--s` 옵션을 주면 위원회 평가를 건너뛰고 모든 클라이언트에 같은 가중치(1/10)를 주는 **단순 평균 집계(FedAvg 비교군)** 로 동작합니다. 데이터 양에 따른 가중은 하지 않습니다.

## 실험 설정 (mainv2.7.py 기준)

| 항목 | 값 |
|---|---|
| 데이터셋 | CIFAR-10 (`./data`에 자동 다운로드) |
| 모델 | ResNet-18 (CIFAR용으로 첫 conv 3×3, maxpool 제거) |
| 클라이언트 수 | 10 |
| 라운드 / 로컬 에폭 | 50 / 2 |
| 옵티마이저 | SGD (lr 0.01, momentum 0.9), batch 32 |
| 학습 데이터 분할 | **Non-IID**: 클래스마다 최소 10개 보장 후 Dirichlet(α=0.5)로 분배 |
| 위원회 | 3명, CIFAR-10 테스트셋을 클래스 균형(IID)으로 3등분해 각자 보유 |
| EWMA β | 0.3 |
| csf | 1.5 |
| 랜덤 시드 | 42 (데이터 분할·공격 클래스 고정) |

하이퍼파라미터는 스크립트 상단의 상수(`NUM_CLIENTS`, `NUM_ROUNDS`, `EWMA_BETA` 등)에서 바꿉니다.

## 공격 시뮬레이션

| 공격 | 옵션 | 동작 |
|---|---|---|
| 랜덤 노이즈 | `--ns N` | 학습 없이 무작위로 초기화된 모델 파라미터를 제출 |
| 데이터 포이즈닝 | `--df N K` | 무작위로 고른 K개 클래스의 라벨을 다른 클래스로 바꿔 학습. N명 모두 **같은 클래스를 같은 방식으로** 바꾸는 집중 공격 |

공격자는 클라이언트 번호 뒤쪽부터 배정됩니다. (포이즈닝 → 노이즈 순) 포이즈닝 시에는 오염된 클래스의 정확도를 따로 추적합니다.

## 실행

```bash
pip install torch torchvision "flwr[simulation]" numpy pandas matplotlib
```

```bash
python mainv2.7.py [--s] [--ns N] [--df N K] [--csf F]
```

| 옵션 | 설명 | 기본값 |
|---|---|---|
| `--s` | 위원회 평가 생략 (FedAvg 비교군) | 꺼짐 |
| `--ns [N]` | 랜덤 노이즈 공격자 수 (숫자 생략 시 1) | 0 |
| `--df N [K]` | 데이터 포이즈닝 공격자 N명, 오염 클래스 K개 (K 생략 시 1) | 없음 |
| `--csf F` | 기여도 증폭 지수 | 1.5 |

공격자 수 합계는 `NUM_CLIENTS`(10)를 넘으면 안 됩니다.

### 예시

FedContrib, 공격 없음:

```bash
python mainv2.7.py
```

같은 조건의 FedAvg 비교군:

```bash
python mainv2.7.py --s
```

포이즈닝 공격자 3명(각 3개 클래스 오염)에 대해 FedContrib과 FedAvg 비교:

```bash
python mainv2.7.py --df 3 3
```

```bash
python mainv2.7.py --df 3 3 --s
```

GPU가 있으면 자동으로 사용하며, 클라이언트 하나당 CPU 2개·GPU 0.5개를 할당합니다. (`client_resources`)

## 출력

실행할 때마다 `MMDD_HHMM_v2.7_R{라운드}_[옵션]` 폴더가 생깁니다. 예: `0805_0113_v2.7_R50_[df4L3,skip,csf1.5,ew0.3]`

| 폴더명 약어 | 의미 |
|---|---|
| `ns1` | 노이즈 공격자 1명 |
| `df4L3` | 포이즈닝 공격자 4명, 오염 클래스 3개 |
| `skip` | 위원회 평가 생략 (FedAvg) |
| `csf1.5` | 기여도 증폭 지수 1.5 |
| `ew0.3` | EWMA β 0.3 |

| 파일 | 내용 |
|---|---|
| `federated_learning_results_v2.txt` | 클라이언트별 데이터 분할 현황, 라운드별 정확도·집계 가중치·단계별 소요 시간, 실행 파라미터 |
| `federated_learning_accuracy_v2.png` | 라운드별 글로벌 정확도 |
| `federated_learning_weights_v2.png` | 라운드별 클라이언트 집계 가중치 |
| `federated_learning_poisoned_accuracy_v2.png` | (포이즈닝 시) 오염 클래스 정확도 |
| `federated_learning_full_graph_v2.png` | (포이즈닝 시) 전체 정확도와 오염 클래스 정확도 비교 |

| **`mainv2.7.py`** | **기준 버전.** 전체 vs 오염 클래스 통합 그래프, 라운드 수에 따른 x축 자동 조절, β=0.3 |

## 참고

- 결과 폴더명의 버전 표기(`v2.7`)는 스크립트에 고정된 문자열이라, 다른 버전 스크립트로 실행해도 `v2.7`로 찍힐 수 있습니다. (예: `1027_0651_v2.7_…`는 F1·AUC가 포함된 `main2.7.1_AUC_F1.py` 결과)
- 클라이언트 학습 시간이 모두 기록되므로, 위원회 평가가 추가하는 시간 비용(`cli eval time`)을 FedAvg와 비교할 수 있습니다.
- CIFAR-10 원본 데이터(`data/`, 약 178MB)와 결과 폴더가 커밋되어 있습니다. `.gitignore`에 `data/`, `0*/`, `1*/`가 있지만 이미 추적 중인 파일에는 적용되지 않습니다.
